# Northstar Goods — Concept Storefront

A standalone Next.js storefront concept created as a portfolio project. Includes a responsive editorial landing page, product collection, add-to-bag interactions, quantity controls, subtotal calculation, demo newsletter form, and a separate demo checkout page with an order summary and confirmation screen.

Important: This is a front-end concept only. This is a front-end concept only. Checkout does not create real orders, payments are disabled, and form details are not sent or stored. Product names and prices are illustrative. The cart is passed to the checkout page in the URL for demo purposes only.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.

## Deploy
Import this folder/repository into Vercel. No environment variables are required for the demo.
