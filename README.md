# Northstar Goods — Concept Storefront

A standalone Next.js storefront concept created as a portfolio project. Includes responsive editorial landing page, product collection, add-to-bag interactions, quantity controls, subtotal calculation, and a demo newsletter form.

Important: This is a front-end concept only. Checkout, payments, inventory, customer accounts, and email collection are not connected. Product names and prices are illustrative.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.

## Deploy
Import this folder/repository into Vercel. No environment variables are required for the demo.
